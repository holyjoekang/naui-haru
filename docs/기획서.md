# 나의하루 슈퍼앱 기획서

2026-11-03 기준 · 원본: [나의하루 슈퍼앱 기획서](https://claude.ai/artifact/FEbdZpAcX1rZ5BvDS6hdXS)

## 비전과 문제 정의

목표는 하루 동안 여는 앱 10여 개를, 시간대에 맞춰 필요한 기능만 꺼내 주는 앱 하나로 대체하는 것이다.

- **문제:** 앱마다 기능은 100개지만 실제로 쓰는 건 1\~2개다. 나머지는 광고, 알림, 메뉴 깊이로 시간을 뺏는다.
- **해법:** 내가 쓰는 기능만 카드로 모으고, 지금 시간대에 필요한 카드를 맨 위로 올린다.
- **원칙:** 열자마자 3초 안에 원하는 정보 확인, 입력은 한 번의 탭, 광고와 피드 없음, 데이터는 내 것.
- **성공 기준:** 홈 화면에서 지울 수 있는 앱 개수, 하루 앱 전환 횟수 감소.

## 하루 동선

감사일기(2026년 1월\~11월, 161일치)를 보면 평일은 새벽 기도 → 지하철 출근 → 회사 → 운동·반려견 산책 → 일기·글쓰기의 일정한 흐름이고, 주말은 예배와 여행이 중심이다.

> 하루 동선 다이어그램(시간대 6개)은 원본 문서에서 볼 수 있다.

일기는 “출근후 8시21분”, “저녁 8시 10분”처럼 시간을 먼저 적고 말하듯 쓰는 형식이다. 그래서 앱의 일기는 하루 여러 번, 시간이 자동으로 찍히는 음성 입력이 맞다. 상단 시간대는 일기에 자주 나온 시각을 기준으로 잡았다.

## 기능 목록

MVP는 직접 저장하는 네 기능(할 일·메모, 습관, 일기, 날씨)부터 만들고, 외부 계정이 필요한 기능은 2단계로 미룬다.

| 기능 | 실제로 쓰는 핵심 동작 | 대체할 앱(예시) | 우선순위 |
| --- | --- | --- | --- |
| 할 일 · 메모 | 오늘 할 일 체크, 번쩍 떠오른 메모 한 줄 | 투두 앱, 메모장 | 1단계 |
| 날씨 | 지금 기온, 강수 확률, 미세먼지 | 날씨 앱 | 1단계 |
| 습관 · 건강 | 물, 운동, 수면 등 하루 체크 | 습관 앱, 걸음 앱 | 1단계 |
| 일기 | Google Docs 감사일기 바로 열기, 오늘 썼는지 표시 | 일기 앱 | 1단계 |
| 일정 | 오늘 일정 목록과 다음 일정까지 남은 시간 | 캘린더 앱 | 2단계 |
| 지하철 | 바로타 웹앱 열기(출근·퇴근 모드) | 지하철 앱 | 1단계 |
| 뉴스 | 관심 키워드 헤드라인 5개 | 포털, 뉴스 앱 | 2단계 |
| 메일 | 안 읽은 중요 메일 제목만 | 메일 앱 | 3단계 |

이 목록 밖의 기능(가계부, 버스, 주식 등)은 카드 하나씩 추가하는 방식으로 나중에 붙인다.

감사일기에서 반복해서 나온 활동으로, 아래 다섯 카드를 추가한다.

| 기능 | 실제로 쓰는 핵심 동작 | 일기에 나온 모습 | 우선순위 |
| --- | --- | --- | --- |
| 새벽기도 · 말씀 | 오늘의 말씀, 기도제목, 찬양 바로가기 | 거의 매일 새벽 4\~5시대 | 1단계 |
| 운동 기록 | 달리기·수영 거리와 시간 한 줄 입력, 주간 누적 | 달리기 8.5km 56분, 수영 1km 30분 | 1단계 |
| 토리 산책 | 오늘 산책 했는지 체크 | 퇴근 후·밤 산책이 자주 등장 | 1단계 |
| 퇴근 카운트다운 | 출근 시각 기준 퇴근까지 남은 시간 | “8시간 반 있다가 나가면 됨”을 직접 계산 | 1단계 |
| 블로그·사업 메모 | 글감 메모, 하루 한 편 체크, 사업·투자 아이디어 | “블로그 하루 하나”, 사업계획 미팅 | 2단계 |

## 화면 구성

화면은 홈 하나뿐이고, 지금 시간대에 맞는 카드가 자동으로 맨 위에 올라온다.

1. **상단 인사말:** “좋은 아침, 7:12” 처럼 시간대 이름과 날씨 한 줄.
2. **지금 카드 (2\~3개):** 시간대에 맞춰 바뀜다. 아침은 날씨·오늘 할 일·일정, 출근길은 지하철·뉴스, 밤은 습관 정산·일기.
3. **나머지 카드:** 접힌 상태로 아래에. 탭하면 펼쳐짐.
4. **빠른 입력 버튼(하단 +):** 할 일, 메모, 일기 중 하나를 골라 바로 입력.
5. **설정:** 시간대 경계, 카드 순서, 출퇴근 역, 습관 목록.

모든 카드는 같은 틀(제목 · 핵심 숫자/목록 · 한 번의 동작)을 써서, 새 기능을 카드 하나로 더할 수 있다.

## 데이터·연동

내가 쓰는 기록은 앱이 직접 저장하고, 세상 정보는 공개 API나 기존 계정 연동으로 읽어오기만 한다.

| 구분 | 항목 | 가져오는 방법 | 비고 |
| --- | --- | --- | --- |
| 직접 저장 | 할 일, 메모, 습관, 일기 | Google Sheets 1개 파일(shinjoe.kang 계정)에 저장, PC·폰 어디서나 같은 데이터 | Apps Script 웹앱으로 읽기·쓰기, 시트에서 직접 보고 고칠 수 있음 ([설치](구글시트-연동.md)) |
| 공개 정보 | 날씨, 미세먼지 | 기상청·에어코리아 공공데이터 또는 무료 날씨 API | 송파구 잠실 고정 |
| 공개 정보 | 지하철 도착 정보 | 직접 만든 [바로타](https://barota-five.vercel.app/) 웹앱이 처리 | 역 설정은 바로타에 저장, 슈퍼앱은 바로가기만 |
| 공개 정보 | 뉴스 | 뉴스 RSS 또는 검색 API | 관심 키워드로 필터 |
| 내 계정 | 일정, 메일 | Google 계정 2개(holyjoekang·shinjoe.kang) 연동, 합쳐서 표시 | 읽기 전용 권한만 |

연동이 어려운 기능은 해당 앱·웹으로 바로 열리는 바로가기 카드로 우선 대신한다.

## 개발 로드맵

세 단계로 나눠, 각 단계가 끝날 때마다 바로 매일 쓸 수 있는 상태로 만든다.

1. **1단계 — 나의 기록 (MVP):** 시간대별 홈, 할 일·메모, 습관 체크, 한 줄 일기, 날씨 카드. PC·폰 어디서나 여는 웹 앱.
   - 완료 기준: 1주일 동안 투두·메모·습관·일기 앱을 열지 않고 지내기
2. **2단계 — 세상 정보:** 지하철 도착, 관심 뉴스, 일정 연동, 바로가기 카드.
   - 완료 기준: 출근길에 이 앱 하나만 열기
3. **3단계 — 똑똑해지기:** 메일 요약, 주간 되돌아보기(습관 달성률·일기 모아보기), 홈 화면 설치(PWA), 알림.
   - 완료 기준: 홈 화면에서 대체된 앱 삭제
