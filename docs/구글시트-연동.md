# Google Sheets 연동

나의하루의 기록(할 일, 메모, 운동, 하루 체크, 습관, 설정)은 내 Google 스프레드시트에 저장됩니다. 기기에는 오프라인용 사본만 남고, PC·폰 어디서 열어도 같은 기록이 보입니다.

## 설치 (한 번만, 약 5분)

1. [sheets.new](https://sheets.new)로 새 스프레드시트를 만들고 이름을 `나의하루`로 바꿉니다.
2. **확장 프로그램 → Apps Script**를 엽니다. `Code.gs` 내용을 모두 지우고 이 저장소의 [`gas/Code.gs`](../gas/Code.gs)를 붙여 넣은 뒤 저장합니다.
3. 위쪽 함수 목록에서 `setup`을 고르고 **실행**합니다. 권한 요청이 나오면 허용합니다.
   - 시트에 `할일·메모·운동·하루·습관·설정` 탭이 생깁니다.
   - **실행 로그**에 나온 `비밀 키: ...` 값을 복사해 둡니다.
4. **배포 → 새 배포 → 유형: 웹 앱**을 고르고 다음처럼 정합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (비밀 키가 있어야 읽고 쓸 수 있습니다)
   - 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
5. 나의하루 앱에서 **⚙︎ 설정 → Google Sheets 저장**에 URL과 비밀 키를 넣고 **연결**을 누릅니다.
   - 이 기기에 이미 있던 기록은 시트로 옮겨집니다.
   - 다른 기기(폰·PC)에서도 같은 URL과 키로 한 번씩 연결하면 됩니다.

## 동작 방식

| 상황 | 동작 |
| --- | --- |
| 기록을 고침 | 1.5초 뒤 시트로 저장 |
| 앱을 열거나 다시 볼 때 | 시트에서 최신 기록을 가져옴 |
| 오프라인(지하철 등) | 기기에 쌓아 두었다가 연결되면 저장 |
| 두 기기에서 따로 고침 | 할 일·메모·운동은 합치고, 하루 체크는 한쪽이라도 했으면 완료로 표시 |
| 시트에서 직접 고침 | 다음에 앱을 열 때 반영 (편집 중이던 기기는 합쳐서 반영) |

- 연결 정보(URL·키)는 각 기기에만 저장되고 시트에는 올라가지 않습니다.
- 시트의 날짜·시각은 글자로 저장됩니다. 직접 고칠 때 `2026-11-03`, `08:20` 형식을 지켜 주세요. 완료 여부는 `TRUE`/`FALSE`입니다.
- 한쪽 기기에서 지운 항목이, 동시에 다른 기기에서 고치던 중이면 다시 살아날 수 있습니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로).
- 비밀 키를 바꾸려면 Apps Script **프로젝트 설정 → 스크립트 속성**에서 `KEY` 값을 바꾸고 각 기기에서 다시 연결합니다.
