# 나의하루

하루에 여는 여러 앱 대신, 시간대에 맞춰 필요한 카드만 맨 위로 올려 주는 나만의 슈퍼앱 (1단계).

- 시간대: 새벽 04:30 · 출근길 07:00 · 회사 08:20 · 퇴근 후 18:00 · 저녁 20:00 · 취침 22:00 · 주말 (설정에서 변경)
- 카드: 새벽기도·말씀, 날씨(잠실, Open-Meteo), 지하철(바로타 바로가기), 퇴근 카운트다운, 할 일, 메모, 운동 기록, 토리 산책, 감사일기(Google Docs 바로가기), 습관 정산, 뉴스(키워드)
- 데이터: 브라우저(localStorage)에 저장. 설정 → 데이터 내보내기/가져오기로 백업·기기 이동
- 뉴스: `api/news.js` (Vercel 함수, Google News RSS)
- 홈 화면에 추가하면 앱처럼 실행 (PWA)

## 배포
정적 파일 + `api/` 함수. Vercel에 저장소를 연결하면 빌드 설정 없이 배포됩니다.
