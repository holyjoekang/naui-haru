# 나의하루

사이트: https://naui-haru.vercel.app

하루에 여는 여러 앱 대신, 시간대에 맞춰 필요한 카드만 맨 위로 올려 주는 나만의 슈퍼앱 (1단계).

- 시간대: 새벽 04:30 · 출근길 07:00 · 회사 08:20 · 퇴근 후 18:00 · 저녁 20:00 · 취침 22:00 · 주말 (설정에서 변경)
- 카드: 새벽기도·말씀, 날씨(잠실, Open-Meteo), 지하철(바로타 바로가기), 퇴근 카운트다운, 할 일, 메모, 운동 기록, 토리 산책, 감사일기(Google Docs 바로가기), 습관 정산, 뉴스(키워드)
- 데이터: 내 Google Sheets에 저장(`gas/Code.gs` Apps Script 웹앱), 기기에는 오프라인 사본. 설치는 [docs/구글시트-연동.md](docs/구글시트-연동.md). 연결 전에는 이 기기에만 저장되며, 설정 → 데이터 내보내기/가져오기로 백업 가능
- 뉴스: `api/news.js` (Vercel 함수, Google News RSS)
- 홈 화면에 추가하면 앱처럼 실행 (PWA)

## 기획
[docs/기획서.md](docs/기획서.md) — 비전, 하루 동선, 기능 목록, 화면 구성, 데이터·연동, 로드맵

## 배포
정적 파일 + `api/` 함수. Vercel 프로젝트 `naui-haru`에 연결되어 있어 main에 올리면 자동으로 배포됩니다.

## 그림
시간대마다 빈센트 반 고흐의 그림이 헤더에 걸립니다 (`art/`, 모두 퍼블릭 도메인). 새벽 「별이 빛나는 밤」, 출근길 「씨 뿌리는 사람」, 회사 「붓꽃」, 퇴근 후 「사이프러스가 있는 밀밭」, 저녁 「밤의 카페 테라스」, 취침 「론강의 별이 빛나는 밤」, 주말 「꽃 피는 아몬드 나무」. 바꾸려면 `app.js`의 `ART`를 고치면 됩니다.
